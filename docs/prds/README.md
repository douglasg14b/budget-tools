# Product requirements

PRDs in this directory describe **intended product behavior**, UX, and non-negotiable constraints. They are not implementation plans. Plans and design docs link here; they do not replace these documents.

Mark requirements **Done** / **Not done**. Cite existing code and design docs instead of copying them.

## PRDs

- [Receipt taking](receipt-taking.md) — in-app capture, extract, match, persist, and classify/split context for grocery (and similar) receipts. Amazon payees stay on `amazon-suggest`; no Amazon receipts.
